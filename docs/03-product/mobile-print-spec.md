# مواصفة القوالب والطباعة المحلية للجوال

**الملخص:** [assumption] معاينة كرت وورقة A4 وإنتاج PDF وإعادة طباعة المؤكد، مع فصل التصميم عن حسابات الراوتر؛ مسودة للاعتماد.

## المشكلة والهدف
- [assumption] تمكين PER-001 من إكمال [احتياجات الطباعة](../01-discovery/network-owner-workflows.md) دون تعديل حسابات الراوتر أثناء التصميم أو إعادة الطباعة.
- [assumption] النجاح: الملف والورقة يطابقان الكروت المختارة والرموز والمقاسات، وتقبل المحاذاة على طابعة المؤسس.

## رحلة المستخدم
1. [assumption] يفتح دفعة مؤكدة أو يختار جزءًا منها؛ يوضح العدد المتاح للطباعة وأي أسرار مفقودة أو غير صالحة.
2. [assumption] يختار قالبًا جاهزًا أو صورة خلفية بلا بيانات دخول، ثم يظهر كرت تجريبي منفصل عن رموز الدفعة.
3. [assumption] يحدد الحقول الظاهرة: اسم الشبكة والرقم وكلمة المرور وملخص الباقة والسعر ووسم نقطة البيع والتسلسل بحسب البيانات المتاحة.
4. [assumption] يظهر/يخفي الحقول بجوار معاينة الكرت، ويحدد الحقل عليها ثم يسحبه؛ يتحكم بحجم خطه ولونه مع توسيط وإعادة موضع وتراجع. لا تعرض منزلقات «أفقي/رأسي»؛ حركة لوحة المفاتيح بديل للوصول عند توفرها.
5. [assumption] يضبط المقاس الفعلي والهوامش والصفوف والأعمدة والمسافات، أو وضع البيانات فقط لورق مطبوع سابقًا.
6. [assumption] يعاين الورقة والقص وعدد الصفحات؛ أي تجاوز للمساحة يمنع الإنتاج مع تحديد القيمة المطلوب تعديلها.
7. [assumption] يجهز PDF مع تقدم وإلغاء، ثم ينزله أو يشاركه أو يفتح طباعة النظام بفعل مستقل.
8. [assumption] يبدأ بورقة اختبار؛ لا يعلن التطبيق طباعة الورق إلا بإقرار مستقل من المالك إن كانت هذه المعلومة مطلوبة.

## تهيئة القوالب حسب الباقات
- [assumption] عند دخول التصميم من دفعة، يبقى مرجعها ثابتًا والحفظ يعيد إليها. معاينة الورق تستخدم كروتها المؤكدة وحقولها ونفس القالب، مع تنقل الصفحات وتكبير كرت لفحصه؛ تعديل الصفوف والأعمدة أو القالب لا يولد أرقامًا جديدة ولا يغير حقوق الإصدار.
- [assumption] تجربة قالب دون دفعة تعرض عينات مسماة بوضوح، ولا تستخدم كمية أو أرشيفًا وهميًا. اعتماد طباعة محذوف أو ثبت تغيره يستبعد مع بيان العدد المقيد، ولا تعرض أسرار قديمة بدلًا عنه؛ السياسة الأساسية في [الأرشيف](mobile-archive-spec.md).
- [confirmed] طلب المؤسس قراءة الباقات، اختيار قالب أو صورة لكل باقة، تحديد مواضع اسم المستخدم والحقول وإمكان QR والملاحظة ونقطة البيع، وتخطي الباقات غير المطلوبة؛ المصدر: محادثة 2026-11-13.
- [assumption] بعد فحص الربط تعرض الباقات المتاحة مع النظام والحقوق، ثم حالات «لم يجهز» و«جاهز» و«متخطاة»؛ تجهيز القوالب كله قابل للتأجيل ولا يحجب فحص الكرت.
- [assumption] القالب مرتبط بهوية الراوتر والنظام والباقة، لا باسم الباقة وحده. باقتان باسم «يومية» من Hotspot وUser Manager لا تتشاركان الإعداد ضمنيًا.
- [assumption] الباقة المختارة تقدم خلفية جاهزة أو صورة محلية؛ فوق المعاينة أو بجوارها مفاتيح مسماة لرقم الدخول وكلمة المرور واسم الشبكة والباقة والسعر والدعم ونقطة البيع وQR والملاحظة. إظهار الحقل يحدد ما سيطبع، وتحديده على الكرت يفتح أدواته دون حفظ تلقائي للتعديل.
- [confirmed] رفض المؤسس منزلقات الموضع وطلب التحكم المباشر مع تكبير/تصغير الخط ولونه وصفوف الورقة وأعمدتها؛ المصدر: محادثة 2026-11-13، [D-050](../04-decisions/D-050-novice-owner-interactions.md).
- [assumption] السحب والتوسيط وإعادة الموضع والتراجع تجعل الأثر ظاهرًا وقابلًا للتصحيح؛ لا تعاد إحداثيات الموضع باسم آخر. اختيار صورة لا يرفعها للخادم أو يمنح وصولًا كاملًا لمكتبة الصور.
- [assumption] الصفوف والأعمدة ضمن إعداد الورقة في نفس رحلة القالب، مع عدد الكروت في الصفحة ومعاينة توزيع A4 وعدد الصفحات؛ مواضع الحقول وتكبير الخط لا تغيران عدد الكروت أو الباقة.
- [assumption] اسم الشبكة والدعم يرتبطان بملف الشبكة المختار في [مواصفة الإعداد](mobile-account-setup-spec.md)؛ رقم الحساب ورقم التواصل الخاص لا يظهران تلقائيًا.
- [assumption] الملاحظة ونقطة البيع حقول اختيارية؛ نقطة البيع المطبوعة لا تثبت بيعًا أو تحصيلًا. دعم اختلاف كلمة المرور عن الاسم يحفظ الفصل بين الحقلين.
- [assumption] QR يحدد محتواه صراحة: رقم كرت أو رابط دخول مضبوط ومختبر. لا يعتمد رابط دخول تلقائي شامل لكل صفحات Hotspot، ولا توضع كلمة المرور داخله دون بيان أثر كشفها.
- [assumption] حفظ القالب يثبت نسخة إعداد منفصلة عن المسودة؛ الرجوع لا يدعي الحفظ، والتخطي لا يمحو قالبًا سابقًا. تطبيق قالب على عدة باقات اختيار صريح، مع حقول الباقة الديناميكية ومعاينة لكل منها.
- [assumption] صورة الخلفية تقبل نوعًا وحجمًا موضحين؛ حد 5 MB في المحاكاة قيمة تصميم تجريبية لا حد أداء مثبت، والفشل يبقي القالب السابق.

## الحالات
| الحالة | وش يشوف المستخدم [assumption] |
|---|---|
| لا قالب محفوظ | قوالب توضيحية أو رفع صورة؛ لا صورة تحتوي رموزًا حقيقية |
| تحميل صورة غير صالحة | سبب الرفض والحد المقبول، مع بقاء التصميم السابق |
| تعديل لم يحفظ | علامة واضحة؛ الرجوع يتيح الحفظ أو إبقاء المسودة أو ترك التعديل بعد تأكيد |
| تجاوز ورق | وصف قيمة المقاس/الأعمدة/الهامش المتعارضة، دون إنتاج ناقص |
| تجهيز PDF جارٍ | عدد الكروت المعالجة وإلغاء؛ إلغاء التجهيز لا يمس الدفعة |
| فشل حفظ الملف أو مشاركة | تبقى الدفعة والقالب، وتتاح إعادة المحاولة دون إصدار جديد |
| لا اتصال بالراوتر | طباعة محفوظ مع تنبيه أن صلاحية بيانات الدخول لم تتحقق الآن |
| أسرار مبطلة أو غير متاحة | توضيح عدم إمكان طباعة السر؛ لا تغيير كلمة مرور الراوتر لاستعادتها |
| نافذة الطباعة أغلقت | لا يعلن خروج الورق أو يعتبر الدفعة موزعة أو مباعة |

## الصلاحيات
- [assumption] معاينة القالب بلا أسرار حقيقية؛ فك رموز الأرشيف يحتاج فتح الخزنة المخولة حسب [سياسة الأرشيف المقترحة](mobile-archive-spec.md).
- [assumption] PDF يحوي أسرار دخول؛ تصديره فعل المالك مع تحديد الوجهة، ولا مشاركة تلقائية أو روابط عامة.
- [assumption] إعادة الطباعة لا تستدعي إصدارًا أو تجديدًا؛ التصميم لا يغير الباقة أو حسابات الراوتر.

## اللغة والاتجاه
- [assumption] خط عربي مضمن وأرقام لاتينية تبقى LTR، وتُحفظ الأصفار البادئة؛ النص الحقيقي فوق الخلفية يبقى واضحًا في المقاس الفعلي.

## شروط القبول
- [ ] [assumption] مطابقة عدد الكروت المختارة وعددها في PDF، دون فقد آخر صفحة أو تكرار الرموز عند التجهيز المجزأ.
- [ ] [assumption] اختبار كلمة مرور مختلفة وأطول رمز والأصفار البادئة والعربية ووسم النقطة في المقاس الفعلي.
- [ ] [assumption] اختبار ورقة فعلية وصورة مرفوعة ووضع البيانات فقط، ومعايرة طابعة المؤسس.
- [ ] [assumption] معاينة الهاتف وPDF والورق يتفقون في مواضع الحقول ضمن سماحية تُحدد من الطابعة المختبرة.
- [ ] [assumption] فشل التجهيز أو إلغاؤه أو إعادة الطباعة لا يرسل أي كتابة إلى الراوتر.
- [ ] [assumption] تجهيز باقة وتخطي أخرى والعودة لهما يبقيان الاختيار؛ لا خلط لقوالب اسم متكرر بين الأنظمة أو الراوترات.
- [ ] [assumption] QR فعلي يمسح على الهاتف الآخر وينتج المحتوى المقصود؛ مجرد أيقونة أو موضع في المعاينة لا يجتاز الشرط.
- [ ] [assumption] تغيير الحقول والخط واللون والسحب يعمل في اللمس، والتراجع يعيد الحالة السابقة دون إفساد النسخة المحفوظة؛ لا تعود منزلقات الموضع إلى الواجهة.

## خارج النطاق
- [assumption] تصميم رسومي حر شامل، ضمان كل طابعة Bluetooth/حرارية، إرسال رسائل تلقائي، أو احتساب ملف PDF دليل بيع أو قبض.
