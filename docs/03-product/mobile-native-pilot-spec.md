# مواصفة أول تجربة Expo محلية

**الملخص:** [confirmed] نطاق محدود معتمد في D-055: ربط راوتر اختبار، قراءة الباقات وفحص كرت، إصدار كرت مؤكد وطباعته وإعادة طباعته، ثم اختبار الفشل والاستخدام.
[confirmed] التطبيق عربي/إنجليزي ويعمل محليًا دون حساب سحابي؛ المصدر خطة المؤسس المعتمدة. لا ادعاء توافق أو جاهزية قبل نتائج الاختبار.

## الرحلة وشروط التنفيذ
1. [assumption] يبدأ بمسار حقيقي على الهاتف أو تجربة توضيحية مسماة ومعزولة؛ بيانات التوضيح لا تختلط بأرشيف الراوتر الحقيقي.
2. [assumption] عنوان ومنفذ في بطاقة ربط واحدة ثم بيانات الدخول؛ تنسيق العنوان وفق [مواصفة الربط](mobile-router-spec.md). يكتشف وسيلة الاتصال دون اختيار بروتوكول تقني، ويحذر قبل إرسال اعتماد عبر خدمة غير مشفرة، ولا يخفض حماية بعد فشل شهادة.
3. [assumption] نجاح الربط يتطلب مصادقة وقراءة هوية الراوتر والإصدار. يعزل الباقات والمعرفات والطلبات حسب هوية الاتصال، ولا يدمج راوترين لتشابه IP أو الاسم.
4. [assumption] يقرأ Hotspot وUser Manager حسب الإصدار وقدرات الحساب، بعمليات قراءة محددة دون مسح تاريخ جلسات كامل أو استيراد كلمات مرور قديمة.
5. [assumption] الفحص برقم الكرت، مع اختيار المصدر عند الغموض ووقت القراءة، ويستخدم تفسير الحدود وفق [مواصفة الفحص](mobile-owner-home-spec.md).
6. [assumption] إصدار كرت واحد على الباقة المختارة، مع رقم مولد أو يدوي ومراجعة قبل الكتابة. إذا لم تحمل باقة Hotspot حد الحجم/الوقت صراحة يطلبهما كقيم معلنة؛ لا يخمنهما من مستخدمين سابقين أو يعد بصلاحية لم يثبت إعدادها.
7. [assumption] يحفظ الطلب المشفر قبل الكتابة، ويتحقق من الحساب وإسناد الباقة والحدود. فقد الرد يبقى معلقًا ويمنع إعادة إضافة عمياء؛ التحقق لا يعيد الإصدار. إعادة إسناد/إتاحة حساب جزئي تكون بعد قراءة ومراجعة صريحة.
8. [assumption] النجاح يفتح نفس الكرت للتسليم وPDF/طباعة نظام الهاتف، مع QR لرقم الكرت لا كلمة مروره. فتح الطباعة لا يثبت خروج ورقة أو تسليمها.
9. [assumption] الأرشيف المحلي المشفر يتيح نفس الكرت بعد إعادة تشغيل التطبيق، وإعادة طباعته لا تكتب للراوتر. الملف المصدر يكشف بيانات الكرت باختيار المالك، وتوضح هذه الخطوة قبل المشاركة.

## الحماية والتوافق
- [assumption] بيانات دخول الراوتر في ذاكرة الجلسة للنسخة التجريبية؛ لا حفظ لها في المستودع أو السجلات أو تقارير الخطأ. تحفظ بيانات الإصدار الجديدة في قاعدة مشفرة ومفتاحها في حماية نظام الهاتف؛ لا بديل تلقائي مكشوف إذا تعذر ذلك.
- [assumption] لا تجاوز شهادات TLS أو تبديل إعداد راوتر أو فتح منافذ أو تثبيت سكربت. أنماط خدمات أو إصدارات غير مدعومة تعطي سببًا واضحًا وتمنع إصدارًا لا يمكن التحقق منه.
- [assumption] هذه تجربة التطوير المتوافقة مع وحدات الاتصال الأصلية؛ Expo Go لا يفترض أنه يدعم اتصال TCP أو SQLCipher. متطلبات البناء موثقة مع التطبيق.
- [confirmed] منفذ API ليس منفذ الويب أو Winbox؛ الأصل في [مرجع البروتوكول](../06-mikrotik/api-rest.md). الوصول عبر DDNS يظل مشروطًا بمسار شبكة فعلي.
