# تحقق إصدار الكروت قبل النشر

**الملخص:** [confirmed] استُكمل اختبار دفعات فعلية داخل مختبر RouterOS منفصل عن الشبكات بتاريخ 2026-11-12، بطلب المؤسس 03:34 UTC؛ لم يُفعّل الإصدار العام ولم يُطلب النشر.
[confirmed] المصدر: نتائج أدوات المختبر والمتصفح في هذه الجلسة؛ لا تمثل اختبارًا لراوترات العملاء أو آلاف الكروت.

## النتائج
- [confirmed] شُغّلت النسختان 6.49.19 و7.20.6 مع User Manager الرسمي؛ نجحت دفعات خمسة حسابات لكل نظام، وتكرار أمر الحساب دون تكراره. حدود Hotspot المقروءة كانت 629145600 بايت و5 ساعات.
- [confirmed] أُصدرت من واجهة المالك أربع دفعات، كل منها خمسة كروت: Hotspot وUser Manager على النسختين؛ عرضت الواجهة اكتمال 5/5 بلا فشل. نفّذ الراوتر أمر التسليم وأرسل التأكيد إلى مسار المنصة الفعلي.
- [confirmed] اختبار HTTP المحلي مع check-certificate=yes لم يرسل تأكيد v7؛ عولج إعداد المختبر باستخدام HTTPS وشهادة محلية موثوقة، دون تعطيل فحص الشهادة أو تعديل التطبيق. أعادت مهلة التسليم تنفيذ العنصر غير المؤكد واكتملت الدفعة.
- [confirmed] قُرئ الأرشيف من واجهة المالك، ونُزّل PDF صحيح من دفعة User Manager v7: صفحة واحدة، 66206 بايت. فُحص عرض الهاتف 390px دون تجاوز أفقي أو أخطاء JavaScript؛ لا تأكيد لطباعة الورق.
- [confirmed] اجتازت الاختبارات الحالية 160 اختبارًا في 28 ملفًا؛ آخر إشارة للتطبيق build OK. لم يكشف الفحص الأمني الأساسي مشكلات؛ لا يشمل ذلك تحليلًا أمنيًا عميقًا.
- [confirmed] حُذفت بيانات الراوترين التجريبيين والدفعات وأسرارهما، وأزيل السماح التجريبي؛ راوترات الإنتاج وكروتها لم تُعدّل.

## المتبقي وحدود النشر
- [confirmed] لم تُختبر ملكية الأرشيف من حساب ثانٍ فعلي؛ قراءة السياسات ليست بديلًا عن اختبار جلسة ثانية.
- [confirmed] لم تُستكمل حالات الفشل الجزئي والإيقاف والاستئناف عبر الواجهة أو كرت منفرد بكلمة مرور مختلفة ضمن الدورة الكاملة؛ لا يُسجل اختبار النموذج أو الأوامر كبديل.
- [confirmed] فقدت البيئة ملفات المختبر المؤقتة مجددًا بعد تغيير الإعداد التجريبي؛ استكمال الحالات السابقة يحتاج مختبرًا يبقى متاحًا وحساب اختبار ثانٍ معتمدًا.
- [confirmed] لا تفعيل عام أو نشر قبل إغلاق الحالات المتبقية؛ تصميم القوالب المعتمد بصريًا والطباعة الورقية خارج تحقق هذه الجلسة.
