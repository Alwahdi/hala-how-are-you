# مواصفة الدفعات والأرشيف المحلي للجوال

**الملخص:** [assumption] مكان واحد للدفعات والمسودات والقوالب مع أسرار محمية ونسخ احتياطي قابل للتحقق؛ سياسة تصميم مقترحة، لا تطبيق منفذ.

## المشكلة والهدف
- [assumption] يخدم PER-001 في استرجاع دفعة وإعادة الطباعة وتفسير حالة العمل، ضمن [احتياجات صاحب الشبكة](../01-discovery/network-owner-workflows.md).
- [assumption] النجاح: إيجاد الدفعة الصحيحة، تمييز حالتها وتوقيتها، وإعادة طباعتها أو استكمالها دون إنشاء نسخة مكررة؛ ثم استعادتها من نسخة اختبار.

## رحلة المستخدم
1. [assumption] الرئيسية داخل مساحة الراوتر تظهر غير المكتمل ثم آخر الدفعات؛ «الدفعات» تبحث بالاسم أو الباقة أو وسم نقطة البيع ضمن الراوتر الحالي وتتيح تصفية الحالة عند الحاجة؛ [حدود المساحة](mobile-router-spec.md).
2. [assumption] صف الدفعة يبين الراوتر والنظام والباقة والتاريخ والعدد المؤكد/المطلوب والحالة؛ هوية الدفعة مستقلة عن رقم الكرت.
3. [assumption] التفاصيل تعرض الملخص والكروت المؤكدة والمعلقة والفاشلة، ثم فعل الاستكمال أو الطباعة المناسب؛ تفاصيل الكرت تحمل مصدر القراءة وتوقيتها.
4. [assumption] تغيير القالب أو إعادة الطباعة لا يعدلان سجل الإصدار أو الراوتر؛ وسم النقطة مجرد تخصيص، لا يثبت تسليمًا أو بيعًا أو قبضًا.
   [assumption] مرجع الدفعة ثابت عبر النتيجة والتفاصيل والمعاينة والتسليم؛ تحفظ نسخة حقوقها عند الإصدار، وتظل مختلفة عن تعريف باقة تغير لاحقًا. المسودة الخاصة بتصميم دفعة لا تطبق على دفعة ثانية دون حفظ صريح للقالب.
5. [assumption] المستخدم يفتح خزنة الجهاز عند الحاجة لكشف الأسرار أو تصديرها؛ لا حساب سحابي مطلوب لفتح الأرشيف المحلي.

## السياسة المقترحة للخزنة والنسخ
- [assumption] تشفير أسرار الإصدار محليًا مع حفظ المفتاح في حماية نظام التشغيل؛ لا توضع قاعدة كروت كاملة في مخزن قيم صغيرة ولا ملفات مكشوفة.
- [assumption] تبقى الأسرار حتى حذفها بفعل صريح من المالك؛ لا تنظيف خفي مبني على عدد السجلات. تعديل السياسة أو مدة الاحتفاظ يحتاج اعتمادًا.
- [assumption] بيانات حسابات موجودة قبل Mikro لا يفترض توفر كلمات مرورها؛ أي استيراد أسرار لاحق يحتاج نطاقًا وتفويضًا مستقلين.
- [assumption] تغيير بيانات دخول كرت يُكتشف أثناء القراءة أو ينفذ عبر التطبيق يبطل الطباعة القديمة عند إمكان إثباته؛ عند تعذر الفحص تعرض الحالة غير المتحققة ولا ضمان لصلاحية السر.
- [assumption] نسخة الأرشيف الاحتياطية مشفرة وقابلة للنقل بفعل المالك؛ مفتاح استعادتها لا يعتمد على جهاز مصدر قد يفقده. اختيار أسلوب حماية الاستعادة يحتاج اعتمادًا قبل التنفيذ.
- [assumption] تصدير النسخة يشمل الدفعات والقوالب والصور وسجل التقدم؛ بيانات اعتماد الراوتر تستثنى افتراضيًا وتُعاد عند الربط.
- [assumption] الاستعادة تعرض محتويات النسخة والتعارضات وتفحصها قبل الدمج؛ لا تستبدل قاعدة محلية سليمة أو تكتب إلى الراوتر تلقائيًا.
- [assumption] حذف أسرار الطباعة منفصل عن حذف سجل الدفعة وعن حذف حسابات الراوتر؛ يؤكد الأثر بوضوح ولا يعد بإمكان التراجع عن محو السر بلا نسخة.

## الحالات
- [confirmed] المحاكاة المرتبطة بهذه المواصفة تحفظ دفعات الجلسة فقط؛ نتائج ربطها بالقالب وعزلها وإبطال اعتماد العرض في [سجل التحسينات](mobile-owner-refinements.md). لا تنفيذ خزنة أو استيراد أسرار أو حفظ بعد إعادة التحميل.
| الحالة | وش يشوف المستخدم [assumption] |
|---|---|
| أول استخدام | فارغ حقيقي مع بدء إصدار أو استعادة نسخة، دون أرقام وهمية |
| بحث بلا نتيجة | لا نتائج مع مسح البحث، دون فقد سياق الراوتر |
| سجل قراءة سابق | توقيت القراءة، وفرق حالة الإصدار عن استخدام الكرت الحالي |
| فشل حفظ محلي | يمنع متابعة كتابة لا يمكن تتبعها؛ لا نجاح أرشفة وهمي |
| امتلاء الجهاز | مقدار الحاجة المعروف إن توفر، وحفظ ما أمكن، وخيار إعادة المحاولة |
| نسخة تالفة أو حماية خاطئة | رفض الاستعادة دون تغيير البيانات الموجودة |
| سر محذوف أو غير صالح | السجل باقٍ، والطباعة المقيدة توضح السبب |

## الصلاحيات واللغة
- [assumption] ملكية الجهاز ليست عضوية فريق سحابي؛ الخزنة محلية مع قفل مناسب، ولا يعاد استخدام إثبات هاتف قديم كجلسة سحابية.
- [assumption] عربي/إنجليزي وRTL/LTR؛ رموز الدخول لا تعكس، ولا تعرض الأسرار في نتائج البحث أو الإشعارات أو سجلات التشخيص.

## شروط القبول
- [ ] [assumption] إعادة فتح التطبيق تبقي المسودة والطلب والتقدم والقالب، دون اعتبار المحفوظ تأكيدًا من الراوتر.
- [ ] [assumption] فقدان الإنترنت لا يمنع قراءة الأرشيف أو طباعة سر محفوظ مع بيان حداثته.
- [ ] [assumption] استعادة نسخة تجريبية على تثبيت آخر تعيد الأعداد والصور والرموز والتقدم دون كشف أسرار لغير المخول.
- [ ] [assumption] استعادة نسخة مكررة لا تضاعف الدفعات أو تستأنف أوامر راوتر تلقائيًا.
- [ ] [assumption] حذف أسرار الطباعة لا يحذف حسابات الراوتر، ولا يُعلن نجاح حفظ عند رفضه.

## خارج النطاق
- [assumption] مزامنة أجهزة متعددة، صلاحيات فريق، دفتر محاسبة، استرجاع نسخة بلا وسيلة فكها، أو ضمان إلغاء PDF سبق تصديره من جهاز المالك.
