# مواصفة رقم التواصل وإعداد الشبكة للجوال

**الملخص:** [confirmed] طلب المؤسس إدخال الرقم حتى بدون توثيق أو إنترنت، ثم مراجعة الطلب من طرفه لاحقًا؛ المصدر: إجابة توضيح في محادثة 2026-11-13.
[confirmed] اسم الشبكة ومكانها وأرقام التواصل إعداد اختياري قابل للتخطي؛ الهدف دعم المستخدمين والتحديثات والميزات المدفوعة لاحقًا.
[assumption] هذه مواصفة تجربة للمراجعة، وليست جلسة دخول منفذة أو اعتمادًا لتجميع بيانات فعلي أو اشتراكات.

## المشكلة والهدف
- [assumption] يخدم صاحب الشبكة PER-001 ويقلل تعقيد البداية المرتبط بـP-003؛ التعريفات في [المشاكل](../01-discovery/problems.md).
- [assumption] النجاح: يبدأ المستخدم عمله المحلي بعد إدخال الرقم دون انتظار رمز أو إدارة، ويعرف ما سيرسل وما سيظهر على كروته.

## رحلة المستخدم
1. [confirmed] يكتب رقم التواصل؛ التوضيح الأخير من المؤسس يلغي اشتراط رمز قبل بداية العمل في هذا التصور، ولا يلغي إمكان التوثيق لاحقًا.
2. [assumption] يختار مفتاح الدولة؛ يقبل الرقم الدولي الكامل دون إضافة المفتاح مرتين. التنفيذ الحقيقي يستخدم تحقق مكتبة أرقام دولية، لا طول الرقم وحده.
3. [assumption] يتضح أن «الرقم غير موثق»؛ عند غياب الإنترنت يبقى طلب الحساب محليًا بحماية الجهاز، مع اختيار واضح لإرساله عند الاتصال. لا يعلن وصوله للإدارة قبل تأكيد الخادم.
4. [assumption] يعرض إعداد الشبكة الاختياري؛ حفظ ومتابعة أو تخطي والعودة إليه من الحساب لاحقًا.
5. [assumption] عند إرسال طلبه يمكن للإدارة مراجعته؛ حالات الإرسال والمراجعة وملكية الرقم مستقلة، ولا تمنع المراجعة المعلقة العمل المحلي المسموح.

## البيانات والغرض
| البيانات | الاستخدام المقترح [assumption] | الخصوصية في التجربة [assumption] |
|---|---|---|
| رقم الحساب | متابعة طلب الحساب والدعم | خاص؛ لا يطبع تلقائيًا |
| اسم الشبكة | هوية الشبكة والقوالب | اختياري؛ مرتبط بالشبكة المعنية |
| البلد والمحافظة والمديرية / المنطقة | فهم توزيع الخدمة ودعم المستخدم | البلد افتراضي من دولة الرقم، والقوائم للتحديد الاختياري؛ لا GPS أو عنوان منزل |
| رقم دعم الشبكة | حقل القالب عند تفعيله | منفصل عن رقم الحساب؛ اختياري |
| رقم تواصل إضافي | تواصل خاص بديل | اختياري؛ لا يطبع تلقائيًا |
| قبول رسائل الميزات والعروض | التواصل المستقبلي بهذا الغرض | خيار مستقل غير محدد مسبقًا وقابل للإيقاف |

- [confirmed] طلب المؤسس إزالة سؤال البلد المكرر، وقوائم محافظة ومديرية قابلة للبحث بدل الكتابة؛ المصدر: محادثة 2026-11-13، [D-050](../04-decisions/D-050-novice-owner-interactions.md).
- [assumption] البلد الافتراضي من دولة الرقم، بما فيها الرقم الدولي الملصوق؛ يظهر كملخص مع «تغيير» عند اختلاف بلد الشبكة، لا كسؤال إلزامي آخر. الرقم ليس دليل موقع أو هوية.
- [assumption] اختيار المحافظة يحدد قائمة المديريات؛ تغيير البلد أو المحافظة يمسح القيمة التابعة غير المتوافقة. البحث يضيق القائمة ولا يغير الاختيار بصمت.
- [assumption] القوائم تأتي من مرجع معتمد بإصدار واضح وتحفظ محليًا للعمل دون إنترنت. نقصها يوضح ويتيح التخطي أو الإبلاغ عن منطقة مفقودة، دون فرض كتابة حرة أو اختلاق قيم.
- [confirmed] المعاينة تضم عينات فقط من عدن وتعز؛ [مرجع OCHA لعدن](https://www.humanitarianatlas.org/yemen/atlasmaps/r-ye2402-ash-shaykh-othman-district-aden-governorate-reference-map-1-november-2019-en-ar-a1-ocha.pdf) و[التقسيم الإداري لتعز](https://www.yemen-nic.info/tourism_site/locations/govers/taiz/classoff/index.php)، مراجعة 2026-11-13. ليست حزمة مناطق كاملة أو تحققًا من أحدث تقسيم؛ باقي البلدان تعرض نقص التغطية صراحة.
- [assumption] بيانات الشبكة تخص هوية الشبكة، وليست قيمة عالمية تنسخ إلى جميع الراوترات دون اختيار؛ تهيئة راوتر آخر تتيح إسناده لشبكة أو تعريفها.
- [assumption] بيانات الدعم تبين منفعتها على معاينة كرت، مع تمييز المعلومات الخاصة عن المنشورة قبل الإرسال أو الطباعة.

## الحالات والملكية
| الحالة | ما يراه المستخدم [assumption] |
|---|---|
| رقم أضيف بلا إنترنت | غير موثق؛ لم يرسل بعد؛ العمل المحلي متاح |
| جارٍ إرسال الطلب | تقدم أو إعادة محاولة دون تكرار الطلب |
| وصل الطلب | بانتظار المراجعة؛ لا ادعاء توثيق رقم الهاتف |
| وافقت الإدارة | تمت المراجعة الإدارية؛ ملكية الرقم تبقى منفصلة |
| الرقم يخص حسابًا سابقًا | لا تفاصيل للحساب ولا دمج أو استرداد بالرقم وحده |
| تغير الهاتف أو تثبيت جديد | الوصول المحلي وفق بياناته؛ استعادة حساب سحابي تحتاج هوية موثوقة |
| تعديل الرقم | طلب غير موثق جديد دون توريث إثبات الرقم القديم |

## الصلاحيات واللغة
- [assumption] طلب الحساب يملك معرفًا مستقلًا محميًا؛ لا يصبح رقم غير موثق مفتاحًا لقراءة بيانات مستخدم آخر أو لكتابة فوقها.
- [assumption] لا توجد جلسة Auth أو صلاحية راوتر من حقل رقم أو إشارة مراجعة إدارية؛ قواعد الهوية الحالية تبقى كما هي. قناة التوثيق إن أضيفت لاحقًا تتبع [D-041](../04-decisions/D-041-keep-whatsapp-verification.md).
- [assumption] طلب الإرسال والموافقة على الرسائل لا يشملان كلمات مرور الراوتر أو أسرار الكروت؛ لا تسجل البيانات الشخصية في ملفات المعرفة أو سجلات التشخيص.
- [assumption] عربي/إنجليزي وRTL/LTR؛ الأرقام باتجاه ثابت، وتسميات «غير موثق» و«لم يرسل» و«تمت المراجعة» مختلفة.

## شروط القبول
- [ ] [assumption] البداية دون إنترنت لا تطلب رمزًا؛ إعادة فتح التطبيق تبقي الطلب المحمي دون ادعاء إرساله.
- [ ] [assumption] تخطي بيانات الشبكة لا يمنع الربط والفحص والإصدار المحلي.
- [ ] [assumption] لا يعاد طلب بلد الرقم في المسار الأساسي؛ البحث والاختيار وتغيير القيم التابعة يعملان دون إنترنت بالقوائم المعتمدة.
- [ ] [assumption] إدخال رقم حساب قائم من جهاز جديد لا يكشف بياناته أو يثبت ملكيته.
- [ ] [assumption] رقم الدعم فقط يظهر على القالب عند اختيار المستخدم؛ رقم الحساب والرقم الإضافي لا ينتقلان تلقائيًا.
- [ ] [assumption] الإرسال المكرر آمن، ويمكن تعديل البيانات وطلب حذف الحساب والبيانات من داخل التطبيق عند وجود حساب فعلي.

## خارج النطاق وبوابات المتابعة
- [assumption] لا تنفيذ لخادم مراجعة أو توثيق أو مزامنة أو دفع في خطوة التصميم. سياسة التسعير والاستحقاقات وتجديد الاشتراك تحتاج خطة مستقلة؛ إرسال تحديث لا يثبت استحقاق ميزة مدفوعة.
- [confirmed] [إرشادات Apple: 5.1.1](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage) تربط طلب البيانات بوظيفتها وتطلب مسار حذف للحسابات المنشأة؛ راجعت بتاريخ 2026-11-13. إلزام جمع رقم لمهمة محلية يحتاج مراجعة ملاءمة المتجر قبل الإطلاق؛ لا ضمان قبول من هذا التصور.
