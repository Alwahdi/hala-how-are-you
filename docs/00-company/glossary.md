# قاموس المصطلحات

**الملخص:** كل مصطلح نستخدمه بمعنى واحد ثابت. أي مصطلح جديد ينضاف هنا قبل ما نستخدمه في أي ملف ثاني.

## الأطراف
| المصطلح | English | المعنى |
|---|---|---|
| صاحب الشبكة | Network Owner | الشخص اللي يملك الشبكة ويبيع الإنترنت، وهو العميل اللي يدفع |
| المهندس | Network Engineer | اللي يركّب الشبكات ويديرها تقنياً، وغالباً يمسك أكثر من شبكة |
| الموزع / نقطة البيع | Distributor / Point of Sale | محل أو شخص يبيع الكروت لصاحب الشبكة مقابل عمولة |
| زبون الشبكة | End Customer | اللي يشتري كرت أو اشتراك ويستخدم الإنترنت |

## الشبكة والتقنية
| المصطلح | English | المعنى |
|---|---|---|
| مايكروتيك | MikroTik / RouterOS | نوع الراوترات ونظامها، وهو الأساس في هذا السوق |
| دمج الخطوط | Load Balancing | توزيع الاستخدام على أكثر من خط إنترنت |
| هوتسبوت | Hotspot | نظام دخول بالكرت، وتظهر فيه صفحة تسجيل دخول للزبون |
| صفحة الهوتسبوت | Hotspot Login Page | الصفحة اللي يشوفها الزبون: الشعار والأسعار ورقم التواصل |
| نقطة بث | Access Point (AP) | الجهاز اللي يوزع الإشارة اللاسلكية |
| وينبوكس | Winbox | برنامج المهندس للدخول على راوترات مايكروتيك |
| الوصول عن بعد | Remote Access | طريقة وصول المنصة للراوتر: عنوان ثابت، أو VPN، أو Cloud، أو Back to Home |
| آي بي كلاود | IP Cloud / DDNS | خدمة مايكروتيك تعطي الراوتر اسم ثابت، وما تشتغل إذا الشبكة خلف CGNAT |
| CGNAT | Carrier-Grade NAT | مزود الخدمة يشارك عنوان عام واحد بين مشتركين كثير، فما تقدر توصل للراوتر من برا |
| نفق | Tunnel (L2TP / SSTP / WireGuard) | اتصال يفتحه الراوتر بنفسه لجهاز مركزي، فيصير الوصول له ممكن حتى لو كان خلف CGNAT |
| عنوان ثابت | Static Public IP | عنوان عام ما يتغير، ونادر في هذا السوق |
| مدير المستخدمين | User Manager | حزمة مايكروتيك لإدارة حسابات الدخول والباقات تعمل كخادم RADIUS |
| RADIUS | Remote Authentication Dial-In User Service | بروتوكول المصادقة والتفويض ومحاسبة جلسات الوصول؛ ليس نفق إدارة عن بعد |
| المستخدمون المحليون للهوتسبوت | Hotspot Users | حسابات دخول محفوظة محلياً في إعدادات الهوتسبوت على الراوتر |
| PPPoE | Point-to-Point Protocol over Ethernet | خدمة وصول بجلسات مصادقة بين عميل (Client) وخادم (Server) عبر Ethernet |
| DHCP | Dynamic Host Configuration Protocol | بروتوكول توزيع عناوين IP وإعدادات الشبكة على الأجهزة |

## البيع
| المصطلح | English | المعنى |
|---|---|---|
| كرت | Voucher / Card | رمز دخول بقيمة ووقت أو حجم محدد |
| اشتراك | Subscription | خدمة شهرية لبيت أو محل |
| باقة | Package / Plan | تعريف للسعر والوقت أو الحجم والسرعة |
| عمولة | Commission | نصيب الموزع من كل كرت يبيعه |
| دفعة كروت | Voucher Batch | مجموعة كروت مرتبطة بعملية إنشاء واحدة لتتبعها دون خلطها بغيرها |
| بادئة / لاحقة | Prefix / Suffix | جزء ثابت قبل رمز الكرت أو بعده |
| تحصيل | Collection | استلام المال وتسجيله؛ ليس مجرد تسليم الكروت أو تفعيلها |
| جرد | Stocktake | مقارنة الكروت الموجودة فعلياً بالسجل في وقت محدد |
| مرتجع | Return | كرت أو مبلغ يعاد ضمن حركة موثقة، مع تحديد أثره على الحساب |
| أمانة بيع | Consignment | كروت لدى نقطة البيع، ويحدد الاتفاق متى تستحق قيمتها وكيف تعاد |

## النمو والتسعير
### مصطلحات المحتوى والسياق
- [confirmed] **مبادئ قابلية الاستخدام (Usability Heuristics):** قواعد مراجعة عامة وليست مواصفات جامدة؛ [المصدر](https://www.nngroup.com/articles/ten-usability-heuristics/).
- [confirmed] **كتابة تجربة المستخدم وتصميم المحتوى (UX Writing & Content Design):** تنظيم المعلومات وكلمات الواجهة حول فهم المهمة والخطوة التالية؛ تعريف العمل بناء على توجيه المؤسس 2026-11-08.
- [confirmed] **الكتابة التحويلية وصوت العميل (Conversion Copywriting & Voice of Customer — VoC):** إقناع صادق يستند إلى لغة عملاء موثقة، لا اقتباسات مصطنعة؛ تعريف العمل بناء على توجيه المؤسس 2026-11-08.
- [confirmed] **الكتابة المتعاطفة وتصميم النبرة (Empathetic Copywriting & Tone of Voice):** تسمية المشكلة الملموسة وخطاب طبيعي يحترم المستخدم؛ تعريف العمل بناء على توجيه المؤسس 2026-11-08.
- [confirmed] **هندسة السرد البصري (Storyboarding & Narrative Flow):** ترتيب المعلومات بصرياً في تسلسل مفهوم دون قفزات؛ تعريف العمل بناء على توجيه المؤسس 2026-11-08.
- [confirmed] **التدويل والتوطين (Internationalization & Localization — i18n & L10n):** دعم اللغات ثم تكييف التجربة مع سياقها؛ تعريف العمل من المرجع المرفق 2026-11-08.
- [confirmed] **تصميم التحويل الواعي بالسياق (Context-Aware Conversion Design):** اسم عمل للمنهج المجمع في المرجع المرفق، لا ادعاء بأنه مسمى معياري عالمي.
