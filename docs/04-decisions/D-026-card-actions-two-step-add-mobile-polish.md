# D-026 خيارات الكرت (تجديد/تعطيل)، إضافة بخطوتين، وصقل الجوال

الملخص: كل كرت عليه قائمة خيارات (⋮): إرسال، تجديد بإضافة باقة لنفس الكرت، التفاصيل، تعطيل/تفعيل بتأكيد وتراجع، وحذف للتجريبي. الإضافة صارت خطوتين: «كرت واحد لزبون» (رقم تلقائي أو مكتوب مع رفض المكرر) ثم إرسال مباشر بـ WhatsApp أو SMS، أو «عدة كروت». كله تجريبي في ذاكرة الصفحة.

- الكرت «قارب على الانتهاء» يظهر عليه زر «تجديد» مباشرة. [confirmed — طلب المؤسس]
- صورة التقرير أعيد تصميمها وتعرض الجلسات وأكبرها وسبب الانتهاء. [confirmed]
- WhatsApp مع الصورة: يصل النص مع الصورة فقط عبر قائمة المشاركة في الجوال؛ رابط WhatsApp العادي لا يرفق صورة، فعند عدم الدعم تُنزَّل الصورة ويُفتح WhatsApp بالنص. [confirmed — قيد تقني]
- الجوال: النافذة السفلية ترتفع فوق لوحة المفاتيح، حقول 16px لمنع التكبير، ونسيج خلفية أخف ومستمر حتى آخر الصفحة. [confirmed]
- لم يُختبر على iPhone/Android حقيقي بعد (لوحة المفاتيح والمشاركة). [assumption]
