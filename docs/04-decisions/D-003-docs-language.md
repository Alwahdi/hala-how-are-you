# D-003: لغة الملفات

**الملخص:**
- قواعد الوكلاء والقوالب وأسماء الملفات بالإنجليزي.
- محتوى الشركة بالعربي، والمصطلحات التقنية بالإنجليزي بين قوسين.

## السياق
المؤسس فوّض القرار ("اللي تشوفه مناسب").

## الأسباب
- **الإنجليزي للقواعد:** الوكلاء يفهمونه بدقة أكبر، ويستهلك كريديت أقل.
- **العربي للمحتوى:** المؤسس والفريق والسوق كلهم عرب، والتفكير بلغتك أوضح.
- **المصطلحات بالإنجليزي:** هي اللي يستخدمها المهندسين فعلاً، وتسهّل البحث.

## البدائل المرفوضة
- **نسختين لكل ملف:** شغل مضاعف، وخطر إن النسختين يختلفن مع الوقت.
- **إنجليزي كامل:** أصعب على المؤسس والفريق.
