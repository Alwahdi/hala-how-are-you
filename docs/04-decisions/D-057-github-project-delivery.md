# D-057: رفع المشروع الكامل إلى GitHub

**الملخص:** [confirmed] طلب المؤسس «انطلق وارفع كلشي ل github» بتاريخ 2026-11-21؛ يعتمد ذلك حفظ وتسليم العمل الحالي إلى مستودعه المرتبط.

## القرار
- [confirmed] رفع مصدر Expo وإعداد EAS والوثائق ودراسات الشخصية ونسخ التصميم التفاعلية وفحوصها إلى المستودع الحالي `Alwahdi/hala-how-are-you` على `main` بعد مراجعة الفروق والملفات.
- [confirmed] حفظ APK الذي نجح بناؤه وفحصه كملف تحميل في إصدار تجريبي منفصل عن سجل المصدر؛ لا نشر متجر أو تغيير صلاحيات المستودع أو إنشاء اشتراك ضمن الطلب.
- [confirmed] تستبعد الملفات البيئية والأسرار وبيانات التشغيل والمجلدات الأصلية المولدة والاعتماديات المحلية من التغييرات المرفوعة؛ لا تغيير لملفات الإعداد القديمة المتتبعة التي لا تدخل في هذا التسليم.
- [confirmed] الحفاظ على سجل Lovable بعمليات commit وpush عادية؛ لا force push أو تعديل لسجل سبق رفعه.
- [confirmed] يسمح نطاق التسليم بتحديث الفهارس وسجل الحالة وخارطة الطريق وREADME وقواعد الاستبعاد اللازمة لفصل فحوص الويب والجوال والتصميم؛ لا بناء ميزة منتج جديدة.

## الأسباب
- [confirmed] اختيار المؤسس الصريح لحفظ العمل على GitHub، والمستودع موجود وله اتصال بالمشروع.
- [assumption] حفظ مصادر التصاميم داخل المستودع يجعل التسليم قابلًا لإعادة الفحص دون مجلد المحادثة المحلي.

## البدائل المرفوضة
- [confirmed] لا رفع لملفات التشغيل المحلية أو مفتاح التوقيع، ولا إعادة كتابة لسجل الفرع المرتبط؛ هذه حدود أمن وتسليم وليست تقليصًا لمصدر المشروع.

## التحقق
- [confirmed] نتائج الرفع ورابط الإصدار والمتبقي تسجل في [سجل التسليم](../05-operations/github-delivery.md)؛ لا يغير رفع المصدر حدود اختبار الراوتر والطباعة.
