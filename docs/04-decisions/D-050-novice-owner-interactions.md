# D-050: مراجعة تفاعل صاحب الشبكة الجديد على التقنية

**الملخص:** [confirmed] طلب المؤسس تقليل التكرار وتبسيط الربط والتحرير والإضافة، وإكمال الفحص بالقائمة والمشاركة والتجديد والشكوى، مع اعتماد JTBD؛ المصدر: محادثة 2026-11-13.
[confirmed] أُعدت مراجعة مهام ومحاكاة محدثة ومواصفات مسودة؛ لا اعتماد تنفيذ RouterOS أو رسائل أو جمع بيانات أو حفظ شخصي فعلي.

## السياق
- [confirmed] وصف المؤسس غالبية المستخدمين المستهدفين بأنهم حديثو استخدام التقنية؛ هذا وصف للمؤسس، وليس نتيجة بحث مستخدمين مستقل.
- [confirmed] أشار إلى عبء إعادة سؤال البلد، وإخفاء إعدادات مهمة، وغموض بيانات دخول الراوتر، وفصل أفعال متقاربة في الرئيسية.

## القرار المقترح
- [assumption] مراجعة الرحلات وفق [المهام واختبارها](../03-product/mobile-jtbd-review.md)؛ تملك المواصفات المرتبطة تفاصيل البلد والربط والقالب والقائمة والرد والتجديد والشكوى، ولا تكرر هنا.
- [confirmed] التعديل يخص التصور وتسليم التصميم ضمن D-047؛ سياسة التجديد ومتابعة الأدلة وقواعد الحفظ وقوائم المناطق الكاملة تبقى للاعتماد قبل التنفيذ.

## الأسباب
- [assumption] حذف سؤال سبق أن أجاب عنه المستخدم، واختيار المهمة قبل إعداداتها، والتحرير قرب النتيجة يقللان ما يحتاج تعلمه وتذكره.
- [assumption] فصل نتيجة مؤكدة عن قراءة ناقصة مهم لفهم الشكوى أكثر من واجهة تعد بإجابة لا تدعمها البيانات.

## البدائل التي رفضها المؤسس لهذه المراجعة
- [confirmed] إعادة طلب بلد الشبكة كحقل مستقل إلزامي بعد اختيار دولة الرقم؛ يبقى تصحيح الافتراض عند الحاجة فعلًا ثانويًا.
- [confirmed] كتابة المحافظة والمديرية يدويًا بدل قوائم قابلة للبحث؛ نقص القائمة لا يبرر اختلاقها أو منع تخطيها.
- [confirmed] مطالبة المستخدم باختيار API TLS أو API غير المشفر في المسار الأساسي.
- [confirmed] منزلقات الموضع «أفقي/رأسي» في محرر القالب؛ البديل تفاعل مباشر، لا إعادة تسمية نفس المنزلقات.
- [confirmed] فصل «إضافة كرت» و«إصدار دفعة» كفعلين أساسيين مستقلين في الرئيسية، وحقل فحص دائم فيها؛ البديلان الجديدان موثقان في مواصفة الرئيسية.

## المخاطر / النتائج
- [assumption] بلد رقم الهاتف افتراض بداية، لا دليل على موقع الشبكة؛ قوائم المناطق تحتاج مصدرًا وإصدارًا وتخزينًا محليًا معتمدًا.
- [assumption] إخفاء خيار التشفير لا يبيح تخفيضه بعد خطأ شهادة أو إعلان نجاح من رقم منفذ؛ دلالات الاتصال في مواصفته.
- [assumption] التجديد ومتابعة MAC والمشاركة لها آثار لا تثبتها المحاكاة؛ البوابات والسياسات وشروط القبول محفوظة في ملفاتها.
- [confirmed] حالة التحقق وحدود الإنجاز في [تسليم التجربة](../03-product/mobile-voucher-experience.md#مراجعة-التفاعل-للمستخدم-الجديد)؛ لا نشر أو تعديل لكود التطبيق.
