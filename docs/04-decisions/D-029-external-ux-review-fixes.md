# D-029: تطبيق ملاحظات مراجعة UX خارجية على تصور الكروت

**الملخص:** اعتمد المؤسس تطبيق النقاط المتفق عليها من مراجعة خارجية (2026-11-11). استُبدلت المربعات الأربعة بشريط فلاتر نحيف فيه الأعداد، وصارت بطاقة الكرت طبقتين، وتوحّد زر الإجراء السريع، ورُفع تباين النص الثانوي.

## المطبق [confirmed]
- شريط فلاتر بالأعداد بدل مربعات الملخص؛ زر «إضافة» بجانب العنوان، والبحث في سطر مستقل.
- البطاقة: رأس (الرقم + الحالة + ⋮ بمساحة لمس 44px) ثم شريط الاستهلاك والتفاصيل ثم زر سريع موحد (outline).
- الأخضر للزر الرئيسي فقط؛ إلغاء زر «تجديد» البرتقالي.
- رفع سطوع `--muted-foreground` وزيادة الحشو الداخلي، وتوحيد حجم وسماكة الأيقونات.

## مرفوض
- اسم «MikroNabd» الوارد في المراجعة: الاسم المعتمد Mikro ([D-009](D-009-final-product-name-company-subdomains.md)).
- لون ثابت `#A0AEC0`: الألوان تُدار عبر الرموز الموحدة فقط.
