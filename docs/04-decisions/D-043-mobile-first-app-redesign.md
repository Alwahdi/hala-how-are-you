# D-043: إعادة التصميم بأولوية الهاتف

**الملخص:** [confirmed] اعتمد المؤسس خطة تحسين الرحلات والعرض بعد دراسة NN/g؛ نُفذ نطاق العرض، ونتائج التحقق في الدراسة المرتبطة.

## السياق
[confirmed] طلب المؤسس تحسين الدخول والحساب والإعداد والإدارة وكل الشاشات مع أولوية الهاتف؛ [الدراسة](../03-product/mobile-first-redesign-review.md) تحفظ الدليل والمراجع.

## القرار
- [confirmed] فصل الحساب وإعدادات الشبكة، وإظهار الراوترات كوجهة مستقلة؛ تنقل مسمى للهاتف وعمود للحاسوب.
- [confirmed] توحيد اللمس والرجوع والنوافذ وحالات القراءة، مع الحفاظ على وظائف الكروت والباقات والهوية الحالية.
- [confirmed] لا نشر أو تعديل سكربت أو صلاحيات أو طريقة تحقق أو تشغيل مهمة راوتر ضمن هذه الخطة.

## الأسباب
- [assumption] الوجهات الواضحة والإظهار التدريجي يقللان البحث والعبء الذهني؛ لا يثبت ذلك تحسنًا مقاسًا دون اختبار الجمهور.

## البدائل المرفوضة
- [confirmed] إبقاء الحساب والراوترات تحت «المزيد»: استبدلته الخطة المعتمدة بوجهات مسماة.
- [confirmed] إضافة إصدار/طباعة أو فريق وصلاحيات ضمن إعادة العرض: خارج نطاق الاعتماد.

## المخاطر / النتائج
- [confirmed] لا شهادة توافق شامل مع NN/g؛ حدود الاختبارات والطلبات المحظورة والاختبار الحقيقي المتبقي في الدراسة.
