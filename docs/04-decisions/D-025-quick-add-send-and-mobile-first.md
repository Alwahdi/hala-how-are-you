# D-025 إضافة كرت سريعة، إرسال فوري للزبون، وتصميم للجوال أولاً (Mobile-first)

الملخص: أصحاب الشبكات يستخدمون الجوال أكثر من الكمبيوتر [assumption — كلام المؤسس، لم يُقس بعد]. لذلك يُصمَّم «تصور الواجهة» للجوال أولاً، مع زر «إضافة» كرت سريع وزر «إرسال» على كل كرت. كل شيء تجريبي في ذاكرة الصفحة فقط.

- الإضافة: باقة وجاهزة (1/3/5/10 GB)، مدة (يوم/أسبوع/شهر/بدون حد)، عدد حتى 20؛ الرقم والرمز يُولَّدان تلقائياً. بعد الإضافة تظهر رسالة جاهزة للزبون (نسخ/WhatsApp/صورة/مشاركة). [confirmed — طلب المؤسس]
- لا ادعاء أن الكرت أُنشئ على راوتر؛ يمكن حذف الكرت التجريبي، ويختفي عند إعادة التحميل. [confirmed]
- الجوال: النوافذ تصبح نافذة سفلية (Bottom sheet) بأزرار ثابتة أسفلها، شريط البحث والإضافة ثابت أثناء التمرير، الفلاتر تتمرر أفقياً، أهداف لمس 44px على الأقل. [confirmed]
- خيار مرفوض: زر إضافة عائم ثابت أسفل الشاشة، لأنه يتعارض مع زر «سجّل اهتمامك» العائم؛ وُضع الزر في الشريط الثابت بدلاً منه.
