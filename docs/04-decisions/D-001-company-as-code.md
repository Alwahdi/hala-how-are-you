# D-001: نبني الشركة كلها ككود

**الملخص:** كل معرفة الشركة تنحفظ في ملفات Markdown داخل المشروع، وهي مصدر الحقيقة الوحيد.
والملفات مرتبة بطريقة تناسب الوكلاء (Agent-Friendly).

## السياق
المؤسس يبي يدير الشركة كاملة عبر الذكاء الاصطناعي، بثلاث شروط:
- أقل أخطاء ممكنة.
- أقل استهلاك للكريديت.
- استمرارية كاملة حتى لو خلص الكريديت أو انتقل لمساحة عمل أو أداة ثانية.

## القرار
- المعرفة كلها في `docs/`، والقواعد في `AGENTS.md`.
- ذاكرة الأداة فيها تفضيلات المؤسس فقط، وتشير للملفات.
- نربط GitHub لاحقاً عشان تكون عند المؤسس نسخة يملكها.

## البدائل المرفوضة
- **المعرفة في المحادثة فقط:** تضيع وما تنتقل لمكان ثاني.
- **قاعدة بيانات وواجهة من البداية:** تكلف أكثر، وتربطنا بأداة وحدة، وتأخر الاستكشاف.
- **ملف واحد كبير:** الوكيل يتجاهل أجزاء منه، ويصرف كريديت أكثر.

## النتائج
كل مهمة لازم تنتهي بتحديث الملفات وملف الحالة، وهذا مكتوب في تعريف "خلصنا" في `AGENTS.md`.
