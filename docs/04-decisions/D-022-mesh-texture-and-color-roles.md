# D-022 نسيج الشبكة المعدنية (Mesh texture) وأدوار الألوان

الملخص: استبدال شبكة المربعات في D-021 بنسيج ثقوب معدنية متداخلة مستوحى من شبك أجهزة الشبكات، مع توهج أخضر. لا يُستخدم شعار MikroTik ولا شكل المكعب السداسي.

- المستويات: خلفية الصفحة (قوي)، أسطح مميزة بركن خافت (`mesh-surface`)، وممنوع خلف النصوص والنماذج والأرقام. [confirmed]
- أدوار الألوان: أخضر = سليم/إجراء رئيسي، بنفسجي = مميز/ترقية، كهرماني = تحذير، أحمر = عطل؛ لا يكون اللون الإشارة الوحيدة. [assumption — علم نفس الألوان عام وغير مختبر على مستخدمينا]
- الأخضر يبقى أسطع من أخضر MikroTik المائل للزرقة لتجنب الإيحاء بارتباط رسمي. [assumption]
- يحل محل جزء النمط في D-021.
