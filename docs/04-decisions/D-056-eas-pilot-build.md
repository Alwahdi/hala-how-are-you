# D-056: بناء تجربة الجوال على EAS

**الملخص:** [confirmed] طلب المؤسس «اكمل واريد ان يكون البناء علئ eas» بتاريخ 2026-11-21؛ هذا اعتماد لنقل بناء نطاق D-055 إلى EAS، دون توسيع ميزات المنتج.

## السياق
- [confirmed] تعثرت بيئة البناء المحلية؛ الأدلة في [سجل التحقق](../03-product/mobile-pilot-verification.md#البناء-والحدود-الحالية).

## القرار
- [confirmed] تجهيز ورفع مصدر تطبيق الجوال فقط إلى EAS تحت حساب Expo المسجل، وإنشاء مشروعه عند الحاجة، ثم بناء Android APK داخلي مستقل باستخدام `preview` ومتابعة النتيجة وإصلاح أخطاء البناء ضمن النطاق المعتمد.
- [confirmed] يشمل الطلب التوقيع المُدار الضروري لتثبيت Android؛ لا تنزيل لمفاتيح التوقيع أو حفظها في المستودع، ولا نشر متجر أو شراء اشتراك أو بناء iOS لجهاز فعلي دون متطلبات توقيعه.
- [confirmed] فحص أرشيف الرفع يسبق البناء؛ بيانات العملاء والراوترات والملفات البيئية وسجل Git خارج الرفع. تبقى البيانات التشغيلية المحلية خارج خدمة البناء.
- [confirmed] يسمح هذا الاعتماد بتحديث إعدادات البناء والفحوص وسجلات التقدم والفهارس المرتبطة؛ لا تغيير للويب أو مصادقة الحسابات أو مهام الراوتر.

## الأسباب
- [confirmed] اختيار المؤسس الصريح لمسار البناء السحابي؛ مصدره الرسالة المذكورة أعلاه.
- [assumption] بيئة EAS المجهزة قد تتجاوز نواقص أدوات الحاسب؛ لا إثبات لنجاح الملف أو تشغيله حتى النتيجة الفعلية.

## البدائل المرفوضة
- [confirmed] استمرار البناء المحلي ليس المسار المطلوب لهذه المحاولة بعد اختيار EAS؛ تبقى أدلته التاريخية محفوظة.

## المخاطر والنتائج
- [confirmed] نتائج البناء والمتبقي ومصدر الإعدادات توثق في [سجل EAS](../03-product/mobile-eas-build.md)؛ نجاح البناء لا يغلق تجربة الراوتر والطباعة والمستخدم.
