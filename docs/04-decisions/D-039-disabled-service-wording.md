# D-039: صياغة الخدمات غير المفعّلة

**الملخص:** [confirmed] رفض المؤسس «مطفية»، واعتمد «غير مفعّلة» للمؤنث و«غير مفعّل» للمذكر؛ المصدر: محادثة 2026-11-12، 01:49–01:50 UTC.

## القرار
- [confirmed] تستخدم الصياغة المعتمدة عند وصف عدم تفعيل خدمة أو إعداد، لا «مطفية» أو «مطفي».
- [confirmed] استُبدلت الصياغة في مزامنة الوقت ومهلة الخمول وخدمة API وUser Manager؛ لا تغيير لوظائف التطبيق أو حالة الراوتر.

## السبب والبديل المرفوض
- [confirmed] البديل العامي مرفوض بتفضيل المؤسس؛ الصياغة المعتمدة أوضح في سياق الإعدادات.

## حدود النطاق
- [confirmed] لا إعادة كتابة شاملة للنصوص ولا تغيير للإنجليزية أو نشر ضمن هذا الاعتماد.
