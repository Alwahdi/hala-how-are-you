## وش الباقي
1. التأكد من المشاكل مع 5 إلى 10 أصحاب شبكات.
2. تحليل المنافسين.
3. تقدير حجم السوق والقدرة على الدفع.
4. التأكد إن الفكرة ممكنة تقنياً، وأولها: كيف المنصة بتوصل للراوترات عن بعد.
5. فهم طرق الدفع المتاحة محلياً.
6. تحديد المخاطر.
