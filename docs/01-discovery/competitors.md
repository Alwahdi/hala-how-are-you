**الملخص:** [confirmed] أُجريت مقارنة مكتبية لسبعة منتجات والبديل الحالي، حسب [الدليل](../playbooks/competitor-analysis.md)؛ المصادر مرفقة.

## مرشحين أوليين للبحث [assumption]
- **أدوات من مايكروتيك نفسها:** User Manager، وThe Dude.
- **أدوات الهوتسبوت والكروت:** Mikhmon، وأنظمة الكروت المحلية في اليمن ومصر وسوريا.
- **أنظمة RADIUS وإدارة المزودين الصغار:** تحتاج بحث.
- **أدوات المراقبة العامة:** تحتاج بحث.
- **البديل الحالي:** المهندس نفسه، ووينبوكس، والواتساب، والإكسل.

[confirmed] القائمة أعلاه محفوظة كبداية البحث؛ المقارنة التالية تغطي ما تحقق حالياً، لا كل أداة في السوق.

## اقتصاديات العرض — دون استنتاج طلب

### SAS Radius
- [confirmed] الصفحة تعرض 250 دولاراً/سنة لـ500 مستخدم، و350 لـ1,000، و500 لـ2,000، و750 لـ5,000، و1,000 لـ10,000؛ غير المحدود بطلب عرض. مكتوب `$/yr`، لا ترخيص دائم. [المصدر](https://snono-systems.com/products/sas-radius/)
- [confirmed] [توثيق الكروت](http://doc.sasradius.com/card-system/) يفرق بين كرت شحن رصيد وحساب مسبق الدفع للهوتسبوت/PPPoE، ويصف PDF/CSV ومصمم قوالب وتعليق دفعة.
- [confirmed] [المديرون](https://doc.sasradius.com/managers/) و[التقارير](http://doc.sasradius.com/reports/) يصفان أرصدة وفواتير وإيصالات وتحويلات؛ [إعدادات الباقة](https://help.snono-systems.com/books/sas-radius/page/profile-form) تتناول الدفع اللاحق.
- [confirmed] يوجد [إعداد نفق وصول](https://doc.sasradius.com/settings/)؛ ليس اختبار كل سيناريو CGNAT. API يسمح بتطبيقات، لا إثبات تطبيق مشمول. عربية الواجهة والجوال ومصفوفة الإصدارات غير متحققة؛ [قناة عربية](https://www.youtube.com/@saseg) دليل محتوى لا مبيعات.
- [assumption] نقاط القوة: الدفعات، التراتبية، التقارير. قيود التقييم: وحدة العد، التجديد، وتوافق/تجربة الواجهة بحاجة فحص.

### DMA Radius Manager
- [confirmed] ترخيص دائم لمضيف واحد، يشمل التركيب الأول وسنة دعم أساسي وتحديثات؛ استمرار التحديث والدعم باشتراك سنوي منفصل. ترقية المستوى لا تجدد الاشتراك تلقائياً؛ المبلغ الحالي غير منشور. [المصدر](https://www.dmasoftlab.com/prices)
- [confirmed] يعلن Hotspot/PPPoE والدفع المسبق/اللاحق والموزعين والفواتير والكروت وAPI، وتوافق MikroTik 2.9–7.x؛ هذا تعهد بائع لا اختبارنا. يعلن 17 لغة دون تحقق أن العربية بينها. [الوصف](https://www.dmasoftlab.com/radman)، [الموقع](https://www.dmasoftlab.com/)
- [confirmed] التحكم في NAS يحتاج مسار شبكة؛ لا تعهد مثبت بنفق مُدار لكل CGNAT. POS وجوال أصلي وديون تجارية تفصيلية غير متحققة في المقارنة.
- [confirmed] [موزع إيطالي](http://www.radiusmanager.it/shop/) يعرض Pro بـ123€ وCTS بـ153€ وCS بـ163€؛ صفحة بلا تاريخ تحديث ظاهر، ليست سعر الشركة الرسمي أو سعر المنطقة.
- [confirmed] [عرض تكنوميم المصري](https://technomeem.com/product/%d8%aa%d9%86%d8%b5%d9%8a%d8%a8-%d9%88%d8%a7%d8%b9%d8%af%d8%a7%d8%af-%d8%b3%d9%8a%d8%b1%d9%81%d8%b1-%d8%b1%d9%8a%d8%af%d9%8a%d9%88%d8%b3-%d9%85%d8%a7%d9%86%d8%ac%d8%b1-dma-radius-manager/) يعرض تركيباً/حزمة بـ1,000 جنيه مصري، بتاريخ 2025-12-27 ومراجعات صفر؛ ليس سعر ترخيص DMA أو إثبات شراء. أنظمة تشغيل قديمة مذكورة، ومصدر حق الترخيص غير متحقق.
- [assumption] نقاط القوة: نطاق فوترة، دوام الترخيص، توافق معلن واسع. قيود التقييم: تحديث مدفوع، نقل المضيف، وعربية/وصول غير محسومة.

### Mikhmon وUser Manager
- [confirmed] Mikhmon V3 مفتوح المصدر، لا RADIUS؛ [تعليمات Bluetooth](https://laksa19.github.io/printBT.html) تثبت مسار طباعة هاتف مع Termux وتطبيق طباعة، لا إدارة ديون POS. V4 Beta2 ظاهر بالموقع؛ عربية أصلية ودعم تجاري وتعهد شامل v7 غير متحققين. [الموقع](https://laksa19.github.io/)
- [confirmed] User Manager يدعم الباقات والجلسات والتقارير وبوابة المستخدم وتوليد الدفعات والقسائم، فلا نفترض أن هذه ميزات مفقودة أصلاً. [الوثائق](https://help.mikrotik.com/docs/spaces/ROS/pages/2555940/User+Manager)
- [confirmed] أسعار RouterOS المنشورة L4: 45$ وL5: 95$ وL6: 250$، وليست رسوماً مستقلة لـUM؛ الأجهزة تأتي بترخيص. حدود UM: 20/50/غير محدود جلسات بحسب هذه المستويات، لا تُخلط بحدود Hotspot أو عدد الأشخاص. [التراخيص](https://help.mikrotik.com/docs/spaces/ROS/pages/328149/RouterOS+license+keys)
- [confirmed] الوثائق القديمة مؤرشفة وتحيل إلى دليل جديد؛ تفاصيل الإصدار والنشر تحتاج تحققاً فعلياً. عربية UM والجوال وديون الموزعين غير متحققة.
- [assumption] قوة Mikhmon: كروت واقتصاد وطباعة هاتف موثقة؛ قيوده: ليس RADIUS، دعم/عربية/توافق غير مضمونين في البحث. قوة UM: موجود لدى المؤسس وباقات ومحاسبة جلسات؛ قيوده: سعة الترخيص، اختلاف الإصدارات، وسجل تجاري خارج نطاق الدليل.
