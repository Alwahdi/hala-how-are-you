# الفرضيات

كل فرضية معها طريقة اختبارها، وكيف نعرف إنها نجحت. ونحدّث الحالة بعد كل اختبار.

## ملاحظات H-005: كيف يوصل المؤسس للشبكات حالياً [confirmed] (المؤسس، 2026-11-05)
- **الطريقة الأساسية:** IP Cloud (DDNS) من مايكروتيك.
- **لو الوصول المباشر ما يشتغل:** الراوتر يتصل بنفق L2TP على راوتر مايكروتيك في بيت المؤسس، والمؤسس يدخل منه.
- **العنوان الثابت (Static IP):** نادر جداً، وما يكون إلا عند الجهات الكبيرة مثل شركات الصرافة.
- **ليش هذا مهم:** طريقة "الراوتر يتصل بنا" (Outbound Tunnel) شغالة فعلاً في الواقع، وهي أفضل نموذج للمنصة. [assumption]
