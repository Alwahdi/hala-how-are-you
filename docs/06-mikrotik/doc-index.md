# فهرس أقسام RouterOS غير المدروسة بعمق

[assumption] روابط للتوسع خارج عمل Mikro اليومي؛ فهرس إحالة لا دليل إعداد. البداية: [Documentation](https://help.mikrotik.com/docs/). بعض الصفحات تنتقل إلى manual.mikrotik.com.

- [Routing Protocol Overview](https://help.mikrotik.com/docs/spaces/ROS/pages/28606515/Routing+Protocol+Overview): تطور دعم التوجيه في v7.
- [BGP](https://help.mikrotik.com/docs/spaces/ROS/pages/328220/BGP): تبادل المسارات بين الأنظمة المستقلة.
- [OSPF](https://help.mikrotik.com/docs/spaces/ROS/pages/9863229/OSPF): توجيه داخلي link-state.
- [MPLS](https://help.mikrotik.com/docs/spaces/ROS/pages/40992794/MPLS+Overview): تمرير بالـ labels للـ backbone.
- [LTE/5G](https://help.mikrotik.com/docs/spaces/ROS/pages/30146563/LTE+5G): المودم وAPN والنطاقات.
- [WiFi / wifiwave2](https://help.mikrotik.com/docs/spaces/ROS/pages/224559120/WiFi): الواي فاي الحديث.
- [Wireless Troubleshooting](https://help.mikrotik.com/docs/spaces/ROS/pages/122388523/Wireless+Troubleshooting): تفسير أخطاء wireless القديم.
- [Container](https://help.mikrotik.com/docs/spaces/ROS/pages/84901929/Container): تشغيل containers ومخاطر العزل.
- [Packages](https://help.mikrotik.com/docs/spaces/ROS/pages/40992872/Packages): الحزم والمعماريات.
- [Disks](https://help.mikrotik.com/docs/spaces/ROS/pages/91193346/Disks): التخزين الخارجي.
- [Software Specifications](https://help.mikrotik.com/docs/spaces/ROS/pages/19136707/Software+Specifications): متطلبات التشغيل.
- [Upgrading to v7](https://help.mikrotik.com/docs/spaces/ROS/pages/115736772/Upgrading+to+v7): تحويل الإعدادات ومحاذيره.

**R-doc-index-1 [assumption]** لا تُفعّل BGP/MPLS/containers من رابط مرجعي دون تصميم واختبار.
