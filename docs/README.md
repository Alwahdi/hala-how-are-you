هذي الخريطة توضح وين كل معرفة الشركة، ومتى تفتح كل مجلد.
ابدأ دائماً من [الحالة](05-operations/status.md)، وبعدها افتح المجلد اللي تحتاجه بس.

| المجلد | وش فيه | متى تفتحه |
|---|---|---|
| [00-company](00-company/) | الرؤية، والمبادئ، وقاموس المصطلحات | تبي تفهم الشركة أو تتأكد من معنى مصطلح |
| [01-discovery](01-discovery/README.md) | المشاكل، والشخصيات، والفرضيات، والعصف الذهني، والمنافسين، والسوق | أي بحث أو تحقق عن السوق والعملاء |
| [02-strategy](02-strategy/README.md) | نموذج العمل، والتسعير، والتسويق | بعد ما نقيّم الفكرة |
| [03-product](03-product/README.md) | النسخة الأولى، ورحلات المستخدم، والمواصفات | قبل أي تصميم أو بناء |
| [04-decisions](04-decisions/README.md) | سجل القرارات وأسبابها | قبل ما تقترح شي، تأكد إنه ما انرفض من قبل |
| [05-operations](05-operations/) | الحالة وخارطة الطريق | بداية ونهاية كل مهمة |
| [playbooks](playbooks/README.md) | طرق العمل المتكررة | لما تسوي مهمة متكررة |
| [templates](templates/) | قوالب الملفات | لما تنشئ ملف جديد |
